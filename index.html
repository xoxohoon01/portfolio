About

성장 과정 & 강점

게임 개발 부트캠프 최종 팀 프로젝트로 Soul Taker를 진행했습니다. 배운 기술을 실제 팀 협업에서 적용하고 싶어 팀장을 맡았고, FSM 기반 몬스터 AI, Object Pooling, NavMesh, Sprite Atlas 최적화를 직접 구현하며 Unity 심화 기술과 팀 리딩 역량을 동시에 키웠습니다. 최종 우수상을 수상했습니다.


부트캠프 수료 후 개인 역량을 더 깊이 쌓고 싶어 Fortune Heroes를 시작했습니다. Addressables 동적 에셋 로딩, 제네릭 기반 UI 시스템(Show<T>/Hide<T>), UGS 데이터 관리를 혼자 설계·구현하며 Unity 아키텍처 이해와 자기주도 학습 능력을 길렀습니다.


게임 개발을 넘어 웹 백엔드도 경험하고 싶어 IoT·클라우드 과정에 참여했고, 최종 팀 프로젝트 Path Note에서 팀장·백엔드 개발자로 REST API 설계·명세서 작성, Spring Security + 카카오 OAuth2, AI 백엔드 서버, DB 설계를 담당했습니다.


Steam 출시를 목표로 Living In Research를 개발하며 P2P 멀티플레이어라는 고난도 기술에 도전했습니다. Steamworks + FacePunch + NGO 조합으로 P2P 구조를 직접 설계하고, NetworkList 기반 인벤토리 동기화, Grid 하우징 시스템을 구현하며 분산 시스템 이해를 심화했습니다.


itch.io에 공개한 Core Catcher를 개발하며 이벤트 훅 기반 아티팩트 시스템, 3단계 크리티컬 설계, 프로시저럴 바이옴 맵 등 로그라이트 핵심 메카닉을 직접 연구·구현했습니다. 개발 과정에서 분리·정제한 툴을 Unity Asset Store에 제작·등록해 실제 판매하는 경험까지 쌓았습니다.
