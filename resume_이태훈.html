자기소개

빠른 습득력과 끝까지 완성하는 실행력을 강점으로 삼는 게임·소프트웨어 개발자입니다. 어린 시절 게임이 선사한 새로운 경험의 가능성에 매료되어 개발을 시작했으며, 기술의 내부 동작 원리를 직접 구현하고 실험하는 방식으로 성장해왔습니다.

내일배움캠프 Unity 트랙에서 팀장을 맡아 FSM 상태 패턴과 Object Pooling을 직접 설계해 CPU 처리 시간을 73% 단축했고, 최종 프로젝트에서 우수상을 수상했습니다. 두 팀 프로젝트 모두 팀장을 맡아 일정 관리와 기술 방향 결정을 이끌며 협업 리더십을 다졌습니다.

부트캠프 이후에도 가중치 랜덤 O(log n) 알고리즘, Steamworks P2P 멀티플레이어 네트워킹, 이벤트 훅 기반 아키텍처와 프로시저럴 맵 생성 등 고난도 기술을 개인 프로젝트로 직접 설계하고 완성했습니다. IoT 클라우드 서비스 교육을 통해 Spring Boot 백엔드·DBMS까지 영역을 확장하며, 게임·웹·네트워킹을 아우르는 멀티 도메인 역량을 갖추었습니다.

개발에 그치지 않고 itch.io 게임 출시와 Unity Asset Store 퍼블리싱까지 직접 경험했습니다. 제품을 시장에 내놓고 피드백을 수용하는 과정에서 기술 완성도와 사용자 관점의 설계를 함께 고려하는 시각을 키웠으며, $117.50 매출·10건 판매의 실적으로 실전 검증된 개발 역량을 갖추었습니다.
